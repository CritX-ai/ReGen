# Changelog

## 1.1.0

- Build profiles, separate review output and tunable HTML/CSS/JavaScript minification, with enforced or warning-only regression checks.
- Opt-in pre/post-build hooks and filename-based slugs when `slug` is omitted.
- `cargo-binstall` support, downloadable bilingual examples and release-tagged containers.
- Clearer guides, deployment examples and source-linked architecture and dependency views.
- Broader platform, feature, packaging and release checks.

## 1.0.0

- Strict multilingual YAML + Tera generation, paired translations and localized URLs.
- Deterministic HTML/CSS output, content-addressed assets, sitemaps and hash manifests.
- Fail-first validation and staged replacement that preserves previous output on preparation failure.
- Cargo installation, six native platform archives, and self-built documentation with a bilingual example.
- CI-derived Rust line-coverage badge in the README and documentation, linked to measured results.
